#  Chat da FÚRIA - Projeto de Experiência Conversacional

Este projeto é um chatbot web simples para os fãs do time de CS:GO da **FÚRIA**. Através de uma interface interativa, o usuário pode enviar mensagens e receber respostas automáticas com base em perguntas comuns sobre o time.

---

## 📌 Descrição

O objetivo do projeto é simular uma **experiência conversacional** com o time da FÚRIA, onde os fãs podem tirar dúvidas rápidas e se engajar com conteúdo pré-definido.

---

## 💻 Tecnologias Utilizadas

- **HTML5 / CSS3**
- **JavaScript (Frontend)**
- **Python + Flask (Backend)**

---

## ⚙️ Funcionalidades

- Chat interativo com respostas automáticas.
- Perguntas sugeridas ao lado direito da tela.
- Imagem da FÚRIA ao lado esquerdo.
- Estilização responsiva em layout flexível.

---

## 🚀 Como Rodar o Projeto Localmente

1. Clone o repositório:

```bash
git clone https://github.com/caiolizardo06/ChatBot-Furia.git
cd ChatBot-Furia
```

2. Instale os requisitos (crie um ambiente virtual se preferir):

```bash
pip install flask
```

3. Execute o servidor Flask:

```bash
python app.py
```

4. Acesse no navegador:

```
http://127.0.0.1:5000/
```
